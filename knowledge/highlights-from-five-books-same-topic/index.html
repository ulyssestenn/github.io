What Should You Do With Highlights From Five Different Books on the Same Topic?

Highlights become more interesting when they stop being about the book they came from.

Donald

Highlights become more interesting when they stop being about the book they came from.

One book gives you quotations. Five books on the same question give you comparison, disagreement, repeated evidence, and the beginnings of an argument of your own.

The mistake is to export everything into one giant note called Highlights and hope synthesis happens later.

Guten Premium's Notes Manager can search and filter highlights and notes across the library, then export either the current filtered set or the full annotation library. That makes it possible to gather material by question rather than by book and move exactly that working set into the next stage of a project.

Start with the question, not the tag

Suppose you have been reading several books about political obligation.

A broad tag such as politics may retrieve far too much. A better working question is:

When do these writers think obedience stops being a virtue?

Now search the Notes Manager for relevant terms, author names, or remembered phrases and filter down to the passages that bear on that question.

The difference matters. A topic is a container. A question creates a comparison.

Other examples:

  • What do these writers mean by progress?
  • Which arguments for toleration depend on religious uncertainty?
  • How do these novels make ambition look admirable before making it destructive?
  • When does memory become evidence rather than merely recollection?

You may already have highlighted the relevant passages for different reasons. Cross-library search lets the later project give them a new relationship.

Bring together fewer highlights than you think you need

A synthesis note does not improve because it contains 80 quotations.

Start with perhaps ten to twenty passages that appear most directly relevant. Read them together outside the flow of their original books.

Then sort them informally by function:

  • writers who make roughly the same claim
  • writers who disagree
  • examples that complicate the apparent agreement
  • definitions
  • evidence
  • passages you still do not understand

This is where highlighting becomes thinking again.

If a passage does not help distinguish, support, complicate, or explain anything, it may not belong in the working set even if it was worth highlighting when you read it.

Write the relationship between quotations in your own words

Two quotations placed next to one another do not constitute synthesis.

Add a sentence explaining why they are together:

Both writers treat habit as politically important, but one sees it as the basis of civic stability and the other as a threat to independent judgment.

That sentence may be imperfect. It is still doing intellectual work the quotations cannot do by themselves.

A useful practice is to alternate between source material and your own claims:

  1. quotation or paraphrase from source A
  2. your statement of what matters in it
  3. quotation or paraphrase from source B
  4. your account of the relation
  5. unresolved question or counterexample

The goal is not to produce a polished essay immediately. It is to stop the archive from doing all the talking.

Keep disagreement visible

A cross-book note can become falsely tidy if every passage is forced under a heading that implies agreement.

If two writers use the same word differently, preserve the difference. If one is describing a historical fact and another is making a normative argument, do not treat them as competing answers to the same kind of question.

Sometimes the most useful result is:

These authors appear to disagree because they are answering different questions.

That is a real finding.

Likewise, do not collapse translation differences or edition differences when exact wording is part of the comparison. Keep enough source information to return to the original passage.

Export the filtered working set

Once the Notes Manager view contains the material for the question, use Export filtered rather than exporting the entire annotation library and separating it afterward.

The filtered set can be exported as:

  • one Markdown file
  • individual Markdown files in a ZIP archive
  • CSV
  • JSON
  • plain text

Markdown export can also use Wikilinks for Obsidian/Logseq workflows or standard portable Markdown links.

For a writing or PKM workflow, Markdown is often convenient because it remains readable and editable. CSV can help when you want to sort or inspect fields. JSON is more appropriate for software workflows. Individual Markdown files are useful when each annotation or note needs to enter a file-based system separately.

The export is not the synthesis. It simply lets the project begin with the relevant reading record instead of the entire library. You still have to decide which evidence belongs together and why.

Preserve the path back to each book

Once passages from five books are mixed together, source identity becomes more important, not less.

For every quotation you might use later, keep enough information to recover:

  • book
  • author
  • chapter or section
  • translator or edition when relevant
  • your original note, if it explains why the passage was saved

A cross-book note should not become a pile of orphaned sentences.

This matters even when the books are all public domain. The intellectual problem is not copyright; it is being able to tell which writer said what and in what context.

Let the collection change the next book you read

Synthesis is useful partly because it exposes what is missing.

After comparing five books, you may discover:

  • all five assume the same historical claim without defending it
  • nobody addresses the strongest counterexample
  • two writers disagree over a term neither defines clearly
  • the books cluster in one period or intellectual tradition

That gives the next reading choice a job.

Instead of adding another book because it shares the topic, choose one that answers the gap the synthesis revealed.

This is where a reading collection becomes more than a storage category. It begins to direct inquiry.

A practical workflow

  1. Name one question.
  2. Search and filter highlights and notes across the library for passages relevant to it.
  3. Reduce the view to a small working set.
  4. Export the filtered set in the format that suits the project.
  5. Group by agreement, disagreement, evidence, definition, or unresolved problem.
  6. Write the relationships in your own words.
  7. Use the gaps to choose what to read next.

The useful thing about having five books' highlights in one system is not that you can admire them all at once. It is that the boundaries between the books stop preventing comparison.
