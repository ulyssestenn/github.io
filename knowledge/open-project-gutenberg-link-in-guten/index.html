How to Open a Project Gutenberg Link Directly in Guten

You do not have to rediscover a book inside the reader just because you found it somewhere else first.

Donald

A Project Gutenberg book often arrives as a link before it arrives as a reading decision. Someone sends it in a message. A search result points to it. A professor links the text. An article mentions a public-domain edition and sends you to gutenberg.org/ebooks/....

If Guten is installed on Android, those ebook links can be handed to Guten. The useful idea is simple: discovery and reading do not have to happen in the same app.

Tap the Gutenberg ebook link

Guten registers for Project Gutenberg ebook URLs. When Android receives a supported https://gutenberg.org/ebooks/... or https://www.gutenberg.org/ebooks/... link, Guten can appear as an app that can handle it.

Choose Guten and the app can use the Gutenberg book identifier from the URL to take you into its own book flow. That saves the small but annoying step of remembering the title, opening a separate catalog search, and finding the same book again.

Android may show a chooser

There is one important detail behind the word “directly.” Guten does not claim verified ownership of gutenberg.org. Ulix does not control that domain, so it cannot publish the Android verification file there.

As a result, Android may show an app chooser when more than one installed app can open the link. That is expected behavior, not a broken deep link. Select Guten when you want the link to become a reading session there.

This is especially useful when discovery happens elsewhere

Public-domain books surface in many places: reading lists, newsletters, Wikipedia articles, library guides, course pages, group chats, and web searches. Requiring every discovery to begin again inside a reader creates unnecessary friction.

A link is already carrying the most important identification data: the Gutenberg ebook number. Let the link do that work.

Open the book, then decide whether to download it

Once you have reached the book in Guten, you can treat it like any other title in the app. If you expect to keep reading, download the EPUB while you have a connection so the book remains available offline.

This is a useful boundary between discovery and possession. The web can help you find the book. Guten can hold the copy you actually plan to read.

Do not confuse link handling with owning the website

Android app links can look seamless when a website and an app are controlled by the same organization. That is not the relationship here. Project Gutenberg is an independent site; Guten is an independent reader built to work with its public catalog.

The correct behavior is therefore modest: Guten says it can understand Gutenberg ebook links, and Android lets you choose it when appropriate.

The tool used in this workflow

Guten

Guten is an Android reader for public-domain books from Project Gutenberg. It can handle Project Gutenberg ebook links on Android, browse and search the catalog, download EPUB books for offline reading, and keep reading progress and bookmarks on the device.
