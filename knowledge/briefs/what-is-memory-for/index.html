What Is Memory For?

Memory helps us imagine the future. Does that tell us what memory itself is for?

Sasha

It seems almost embarrassingly easy to say what memory is for. Memory is for remembering the past.

A substantial argument in psychology and philosophy says that answer may be wrong, or at least much too simple. Episodic memory is reconstructive, fallible, and closely entangled with our ability to imagine events that have never happened. Perhaps its evolutionary job is principally to help predict, simulate, or learn about what comes next.

José Carlos Camillo has now published a defense of the unfashionably literal answer. In the European Journal for Philosophy of Science, he argues that episodic memory's function really is mnemonic: to store and process information about particular past events so their spatial and temporal relations can later be retrieved.

Remembering and imagining share machinery

The case against the simple mnemonic view came partly from the peculiar behavior of memory itself. Memory is not a recording. People omit, combine, distort, and misattribute details. That can look like poor design if accurate preservation is the point.

Then there is imagination. Work by Daniel Schacter, Donna Rose Addis, and others has shown substantial overlap between remembering past episodes and constructing possible future ones. Both draw on a common network that includes the hippocampus. Schacter and Addis's constructive episodic simulation hypothesis proposed that the flexibility that makes memory vulnerable to error is also useful: past details can be taken apart and recombined into events that have never happened.

That is an attractive explanation. But a capacity's usefulness does not by itself establish its evolutionary function.

“What is it for?” is a historical question

Camillo uses an evolutionary notion of function. That makes the question harder than listing everything episodic memory can do now.

He considers four kinds of evidence: the causal role played by episodic memory, what happens when it is impaired, what optimality models suggest, and how competing hypotheses fare. He argues that these lines converge more strongly on storage and retrieval of event-specific information than on alternatives centered on future imagination, counterfactual thought, prediction, or general learning.

He is careful about the limit. We do not possess the evolutionary history or comparative evidence needed to prove the matter conclusively. This is a comparative argument about which hypothesis currently has the better support.

Shared machinery does not settle shared function

Remembering and imagining appear to use overlapping mechanisms. Camillo argues that overlap is not enough. Two operations can share components without being one functional system. Evidence that prediction depends on stored information need not make prediction the storage system's function.

This is a useful philosophical nuisance. Neuroscience can show that two activities recruit overlapping regions. Psychology can show that impairment affects both. Neither observation automatically tells us why natural selection retained the capacity.

Even memory's errors are ambiguous. A distorted memory might reveal a system built for flexible generalization. Or it might show that an accuracy-oriented biological system has constraints and failure modes. Eyes have blind spots without having evolved for not seeing certain patches of the world.

The past can be useful precisely because it is past

A mnemonic account does not require memory to be a museum whose records matter only as records. Accurate information about a particular event can support future behavior, prediction, learning, testimony, planning, and imagination. The disagreement is whether those later uses explain episodic memory's function or are things an event-preserving system makes possible.

A library supports arguments, entertainment, education, and future planning. It does not follow that the function of the catalog is to produce any one of those outcomes. The catalog may have the more modest function of preserving a reliable route back to particular books.

Camillo has not closed the case, and says so. What he has done is make the obvious answer interesting again. Episodic memory may help us imagine tomorrow because it preserves enough of yesterday to give imagination something to work with.
