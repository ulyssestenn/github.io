# Loan It landing page — design concepts

Three directions for the Loan It landing page, all green, all built on the Ulix
site chrome (sticky header, Geist, container widths, footer) and the shared
`.phone` frame used on the Guten and Shelf Scan pages. Every screen shown is a
real capture from `assets/screenshots/loanit/`.

The palette is sampled from the app itself: black surfaces and `#82DB86`, the
green Loan It uses for its own accents.

| File | Direction | Ground | Accent |
|---|---|---|---|
| `a-ledger.html` | House pattern (Shelf Scan / Guten), with loan state as the organising device | `#050906` near-black | `#82DB86` |
| `b-sage.html` | Light and domestic; the app's black screens as high-contrast objects | `#F4F7EE` paper | `#24663A` forest |
| `c-roundtrip.html` | An arc carries the item out and home; monospaced loan ledger | `#07150D` deep forest | `#82DB86` |

These are review previews only — `noindex`, unlinked, and not part of the
published site. Once a direction is chosen, the winner becomes
`/loanit/index.html` with JSON-LD, a canonical URL, a social image, and real
Play Store links, and this folder is deleted.

Screenshots are also committed as `.webp` alongside the source PNGs; the pages
reference the webp versions (2.6 MB of PNG becomes about 380 KB).
