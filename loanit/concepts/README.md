# Loan It landing page — design concepts

Three directions for the Loan It landing page, all green, all built on the Ulix
site chrome (header, footer, Geist, container widths).

| File | Direction | Ground | Accent |
|---|---|---|---|
| `a-ledger.html` | Loan state as the organising device; closest to the Shelf Scan / Curious Air house pattern | `#060C08` near-black, from the app icon's tile | `#2FBF5A` / `#A7E96B` |
| `b-sage.html` | Light, domestic, paper cards; calm rather than technical | `#F4F7EE`, from the app's own light surface | `#24663A` forest / `#7FBF5A` moss |
| `c-roundtrip.html` | Bold; an arc that carries the item out and home, plus a monospaced loan ledger | `#08160E` deep forest | `#B6F05C` lime |

These are review previews only — `noindex`, not linked from anywhere, and not
part of the published site. Once a direction is chosen, the winner becomes
`/loanit/index.html` with real JSON-LD, canonical URL, social image, and Play
Store links, and this folder is deleted.

The in-page app UI (loan lists, cards, ledger rows) is illustrative, drawn in
HTML and CSS. It is not a screenshot and must be replaced with captures from a
release-candidate build before the page ships.
